# 樋川 颯人 / Hayato Hikawa

> 技術的に正しいだけでなく、人・情報・時間・環境まで含めて、実際に価値を生む解決を設計したい。

神山まるごと高専で、ハードウェア、AIソフトウェア、ロボット開発に取り組んでいます。中学生の頃のロケット開発では、回路が動くことに加えて、現場で状態を確かめ、原因を切り分け、復旧できることを考えました。現在は、情報と判断が散らばる状況を扱う実験的なソフトウェア **Atra** を開発しています。
